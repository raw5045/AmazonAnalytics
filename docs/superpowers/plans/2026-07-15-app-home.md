# /app Home → Straight to Explorer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retire the placeholder `/app` hub page; sign-in/sign-up land directly on `/explorer`; `/app` stays alive as a temporary (307) redirect.

**Architecture:** Pure routing/config change. A `next.config.ts` redirect (resolves before middleware and the filesystem) replaces the deleted hub page; four code entry points repoint to `/explorer`; one now-dead middleware matcher entry is removed; three stale comments are corrected; the two Clerk env targets flip locally and (at ship) in Vercel. No schema, no new components, no tests to add — verification is typecheck/test/build plus a live 307 check.

**Tech Stack:** Next.js App Router (`redirects()` in next.config), Clerk env-based redirect targets (`NEXT_PUBLIC_CLERK_AFTER_SIGN_IN_URL` / `_AFTER_SIGN_UP_URL`), Vercel env (ship step).

**Spec:** `docs/superpowers/specs/2026-07-15-app-home-design.md`

**Conventions (repo-wide, non-negotiable):**
- Work directly on `main` (established project convention). Commit locally; **NEVER push** — pushing is owner-gated in Task 3.
- Commit trailer exactly: `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`
- `git add` only named files — never `-A` or `.` (long-standing untracked scratch files must stay untracked).
- `.env.local` contains secrets: edit only the two named lines with the Edit tool, never print the file, never stage it (it is gitignored — do not "fix" that).

const nextConfig: NextConfig = {
  async redirects() {
    return [
      {
        // Old signed-in hub; the explorer is home now. Temporary (307) on
        // purpose: browsers cache 308s forever, and a future dashboard may
        // reclaim /app.

    ];
  },
};

export default nextConfig;
